Site informativo criado por **Vitor Hugo Ribeiro Sá** para auxiliar famílias em uma triagem inicial de sinais relacionados ao Transtorno do Espectro Autista (TEA).

O projeto apresenta informações sobre autismo, perguntas frequentes, serviços, contato, fotos do TCC e um questionário inicial. A proposta é facilitar o acesso à informação e incentivar a busca por avaliação profissional quando necessário.

## Nome do projeto

**Será que é Autismo?**

## Funcionalidades

- Página inicial com chamada para iniciar o questionário.
- Questionário de triagem inicial.
- Área de perguntas frequentes sobre TEA.
- Páginas de serviços, sugestões, contato e fotos do TCC.
- Layout responsivo com menu adaptado para celular.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Como abrir

Abra o arquivo `index.html` no navegador ou publique o repositório usando GitHub Pages.

## Imagem

Imagem do símbolo de infinito do espectro autista disponível no [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Autism_spectrum_infinity_awareness_symbol.svg).

## Observação importante

Este projeto não substitui diagnóstico médico. O objetivo é orientar e incentivar a procura por profissionais especializados.
